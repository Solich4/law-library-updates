# Обновления библиотеки права

Здесь находятся только подписанные пакеты текстов и пояснений, публичная очередь изменений и скрипты мониторинга. Исходники Android-приложения и установочные APK здесь не размещаются.

Приложение читает latest.json и файлы .monitor/ без авторизации. Пакет материалов принимается только после проверки подписи издателя. Закрытые ключи и пароли не публикуются. Тексты и пояснения в пакетах обновления доступны публично; приватность исходного кода приложения на них не распространяется.

GitHub Actions раз в шесть часов проверяет официальные публикации и редакции. При доступном полном тексте формируется короткий технический список добавленных, изменённых и явно отменённых статей. Пропавший заголовок сам по себе не объявляется отменой статьи. Источники могут быть недоступны: в этом случае список остаётся неполным и помечается для проверки. Сроки зависят от доступности источников и запуска GitHub.

Монитор не переписывает нормативные тексты, не создаёт пояснения с помощью ИИ и не подписывает новые пакеты. После проверки издатель вручную публикует пакет текстов и пояснений. Платный ИИ-сервис к этой схеме не подключён.

На телефоне нет фоновых заданий мониторинга: список проверяется при открытии или вручную. Уже начатый запрос может завершиться после сворачивания. См. [обновления](UPDATES.md) и [права на материалы](RIGHTS.md).
